Everything a pharmacy needs
From FIFO dispensing to smart reorder alerts — built for real-world pharmacies.
📦

FIFO Dispensing

Medicines are always dispensed from the batch expiring soonest. The system handles multi-batch deductions automatically.

🚨

Expiry Automation

A daily job quarantines expired batches and flags stock expiring within 7 days — triggerable manually via POST /clock.

📥

Messy Data Import

Import CSVs with mixed date formats, "10 units" quantities, nulls, and duplicates. Get a clean import/deduped/rejected report.

🔔

Reorder Alerts

When in-date stock drops below your threshold after dispensing, a reorder alert is queued automatically in the outbox.

🔍

Search & Filter

Find any medicine or batch instantly. Filter by status, sort by expiry or quantity, paginate large inventories.

🔒

Secure Auth

JWT-based authentication with bcrypt password hashing. Every API call is protected — no accidental data exposure.
